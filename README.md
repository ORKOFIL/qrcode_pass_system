# EntryPass — QR-система керування квитками та контролю доступу

EntryPass — вебзастосунок для створення та керування подіями, квитками та відвідувачами з використанням QR-кодів.

Система дозволяє організаторам керувати подіями й квитками, надавати контролерам доступ до перевірки квитків і фіксувати вхід відвідувачів. Backend реалізований на Node.js та Express із використанням TypeScript, PostgreSQL і Prisma ORM.

## Основні можливості

- **Керування подіями:** створення та керування подіями.
- **Керування квитками:** створення квитків і генерація QR-кодів.
- **Контроль доступу:** перевірка квитків та підтвердження входу.
- **Ролі користувачів:** окремі сценарії роботи організаторів і контролерів.
- **Авторизація:** захист приватних API-маршрутів.
- **Валідація даних:** перевірка вхідних даних за допомогою Zod.
- **Зберігання даних:** робота з PostgreSQL через Prisma ORM.
- **Автоматизоване тестування:** перевірка API та бізнес-логіки.

## Вимоги

Перед запуском переконайся, що встановлено:

- [Node.js](https://nodejs.org/)
- npm
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) або Docker Engine із Docker Compose

PostgreSQL запускається через Docker Compose.

## Локальний запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/ORKOFIL/qrcode_pass_system.git
cd qrcode_pass_system
```

### 2. Налаштування змінних середовища

Створи файл `.env` у кореневій директорії проєкту відповідно до конфігурації backend.

Заповни необхідні параметри, зокрема:
- `DATABASE_URL` — рядок підключення до PostgreSQL;
- секретні ключі access та refresh токенів (можна згенерувати використовуючи uuid);

### 3. Запуск PostgreSQL

У кореневій директорії виконай:

```bash
docker compose up -d
```

Переконайся, що контейнер PostgreSQL запущений і база даних доступна.

### 4. Підготовка бази даних

Встанови залежності backend:

```bash
npm install
```

```bash
npx prisma generate
```

### 5. Запуск backend

У кореневій директорії проєкту виконай:

```bash
npm run dev
```

Backend запуститься в режимі розробки.

### 6. Запуск frontend

Відкрий другий термінал:

```bash
cd client
npm install
npm run dev
```

Після запуску відкрий адресу, яку виведе frontend dev-сервер у терміналі.
